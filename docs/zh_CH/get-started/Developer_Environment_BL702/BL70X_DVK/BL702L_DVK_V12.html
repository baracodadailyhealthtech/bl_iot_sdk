BL70xL 开发说明

概述

BL70xL IoT SDK 支持 Windows, Linux 和 MacOS 操作系统, 支持主流的 GCC编译 和 GDB，Eclipse 调试，用户可以在 SDK/toolchain/riscv 下找到对应的工具链和编译脚本；

而从BL70xL DVK V1.2 开发板角度看， 在不同操作系统下使用略有差异：

  • Windows: 支持 CKLink 和 Sipeed-RV-Debugger 调试器；

  • Linux: 支持 CKLink 和 Sipeed-RV-Debugger 调试器；

  • MacOS：支持 Sipeed-RV-Debugger 调试器；

调试连接

BL70xL 的 JTAG 接口可以通过多种方式连接到电脑上，其中最方便的是板上集成的 CKLink、对于不能使用 CKLink 的用户，也可以使用 Sipeed-RV-Debugger 进行调试连接。

1.1 CKLink 连接

CKLink 是 T-HEAD 开发的 RISC-V JTAG 调试器，BL70xL_IOT_DVK V1.2 上通过 BL616 实现 CKLink 功能，用户直接使用板上的 USB 接口可进行在线调试, 具体使用方法请参考 702L快速入门

调试软件

2.1 Freedom-Studio 调试

Freedom Studio 是 SiFive 公司推出的集成开发环境，已集成编译好的 RISC-V GCC 工具链、OpenOCD、以及一些文档，更适合新手使用。

Freedom Studio 基于 Eclipse IDE 开发，支持 Windows, Linux 和 macOS, 安装和使用参考

2.2 GDB 调试

在 Windows 环境中，通过 CKLink 连接和 T-HeadDebugServer 调试，可使用 GDB 进行在线调试, 参考 702L快速入门。

其它环境下，或通过 Sipeed-RV-Debugger 连接，使用 GDB 进行在线调试，可参考 BL文档 OpenOCD和GDB简介与使用。
