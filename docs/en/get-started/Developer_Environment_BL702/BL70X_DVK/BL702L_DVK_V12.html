BL70xL Development Guide

Overview

The BL70xL IoT SDK is compatible with Windows, Linux and MacOS operating systems, supporting mainstream GCC compilation and GDB, Eclipse debugging. Users can find the corresponding toolchains and compilation scripts in the directory SDK/toolchain/riscv.

From the perspective of the BL70xL DVK V1.2 development board, there are slight differences in usage across different operating systems:

  • Windows: Supports CKLink, Sipeed-RV-Debugger；

  • Linux: Supports CKLink, Sipeed-RV-Debugger；

  • MacOS：Supports Sipeed-RV-Debugger；

Debugging Connection

The JTAG interface of the BL70xL can be connected to a computer in various ways, with the most convenient being the onboard CKLink debuggers. For users who cannot use CKLink, the Sipeed-RV-Debugger can also be used for debugging connections.

1.1 CKLink Connection

CKLink is a RISC-V JTAG debugger developed by T-HEAD. The BL70xL_IOT_DVK V1.2 utilizes the BL616 to implement the CKLink functionality, allowing users to perform online debugging directly through the onboard USB interface. For specific usage instructions, please refer to the 702L快速入门

Debugging Software

2.1 Freedom-Studio Debugging

Freedom Studio is an integrated development environment released by SiFive, which has integrated a pre-compiled RISC-V GCC toolchain, OpenOCD, and some documentation, making it more suitable for beginners。

Freedom Studio is based on the Eclipse IDE and supports Windows, Linux, and macOS. For installation and usage, refer to Freedom Studio Guide

2.2 GDB Debugging

In the Windows environment, online debugging can be performed using GDB through a CKLink connection and T-HeadDebugServer, refer to BL702L Quick Start Guide。

In other environments, or when connected via Sipeed-RV-Debugger, online debugging with GDB can be performed by referring to the BL documentation OpenOCD和GDB简介与使用。
